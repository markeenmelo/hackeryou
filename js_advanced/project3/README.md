## Project setup
```
npm install
```

### Compiles and hot-reloads for development
```
npm start
```
Open the browser and enter the address: `http://localhost:3000`

### Compiles and minifies for production
```
npm build
```

### Run your tests
```
npm test
```

#### .env
```
REACT_APP_API_URL="https://api.themoviedb.org/3/"
REACT_APP_API_KEY="37ecc0c23b6732fd9d464cd99d51f6e1"
```
If required to add new environment variables, Vue requires variable name to starts with `REACT_APP_`.

After adding new variables to `.env` you need to rerun `npm start`.
